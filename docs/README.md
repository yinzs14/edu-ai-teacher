# edu-ai-teacher 项目文档

## 目录说明

| 目录/文件 | 用途 |
|-----------|------|
| `docs/memory/` | 项目进展日志（与 .workbuddy/memory 同步，纳入Git版本管理） |
| `PROJECT_BRIEF.md` | 项目交接文档（技术栈、API、部署信息） |
| `Agent.md` | 开发 Agent 指南（任务状态、设计决策） |

## 跨设备协作
1. 克隆仓库 → `git clone git@github.com:yinzs14/edu-ai-teacher.git`
2. `docs/memory/MEMORY.md` 包含项目规范和服务器信息
3. `docs/memory/` 目录包含每日工作日志，按日期排序阅读最新进展
